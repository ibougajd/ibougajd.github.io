~/projects/ft_transcendence

              
A cloud-native GitOps platform on Oracle Cloud

              
A microservices Pong platform with real-time chat and matchmaking. My part was everything between git push and a healthy pod: the cluster, the pipeline, the secrets, the routing and the monitoring.

              
    
                
  • Cluster — microservices on a K3d Kubernetes cluster hosted on OCI, templated and managed with Helm.
    • 
                
  • GitOps — ArgoCD continuously syncs the cluster with the repo: zero-drift, no manual kubectl apply.
    • 
                
  • CI — GitHub Actions builds the Docker images and pushes them to GHCR.
    • 
                
  • Secrets — cluster secrets and TLS certificates encrypted with SOPS, injected only at deploy time.
    • 
                
  • Edge & observability — Traefik ingress for routing, ELK and Grafana for real-time monitoring.
